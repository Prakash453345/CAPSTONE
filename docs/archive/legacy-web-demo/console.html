Your questions answered.

Because we found and root-caused a real bug rather than hiding it: a fixed switching-cost penalty in the scoring formula outweighs typical traffic pressure by up to 61× at light demand, so the controller ends up running every phase to its maximum timer regardless of actual traffic — confirmed by instrumenting over 44,000 real decisions, not guessed. The fix (rescaling that term) is in progress, and the diagnostic script that found it is checked in alongside the result.
An automated, property-based test suite generates 10,000 randomized cases per invariant — 90,000 total — each specifically engineered to try to trigger a conflicting green, a truncated minimum green, or a starved approach. All 90,000 pass. Five injected hardware failures (lamp failure, comms loss, power restart, and more) each land in a defined, tested safe state rather than an assumed one.
Because every source — simulation now, real cameras and sensors later — has to normalise into the same event contract. Building against the simulation first proves the core architecture can't tell the difference, which is exactly what needs to be true before a real camera feed is trusted with the same decisions.
No, and that's stated plainly rather than implied otherwise: trip generation is randomized (not calibrated origin-destination demand), and the vehicle mix and PCU weights use commonly-cited approximations for a mixed Indian urban arterial, not values measured on this corridor. Real calibration against ground truth comes later, and isn't claimed early.

Accepted

One event bus contract, transport swappable later

A lightweight message bus runs the whole system today, because this phase doesn't need a heavier, more operationally expensive one yet. Every producer and consumer talks to one internal interface, so the transport underneath can change without touching a single caller when it's actually needed.

Accepted

The signal controller is the sole command authority

Every strategy proposes; only the arbiter commands. Interlocks live below arbitration, which makes an unsafe phase structurally unrepresentable rather than merely unlikely.
