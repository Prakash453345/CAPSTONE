One architecture, two scales.

Zones are the scaling axis. A new district is new partitions and new pods, not a new design.

Running now

Phase 1 — Simulation pilot

One machine, three processes, a 20-junction zone driven by SUMO. Everything an operator touches is real; only the street is simulated.

  • SUMO + TraCI as the traffic source adapter
  • Three deployables: sim, api, vision
  • Redis Streams carrying production topic names
  • FastAPI JWT with the production permission taxonomy
  • docker-compose, GitHub Actions, six SLIs from day one

Phase 2 — City deployment

The same contracts unfolded onto real infrastructure, with the adapters swapped and nothing in the core touched.

  • RTSP camera and MQTT sensor adapters
  • Sixteen services on Kubernetes across three zones
  • Kafka with replay for analytics and model training
  • Keycloak, mTLS mesh, row-level tenant isolation
  • GPU inference pool with queue-depth autoscaling

A refused request returns a structured problem response naming the interlock and the time remaining, rather than failing silently. Because the simulation is never thrown away. It is the source adapter for the pilot, the staging environment for every later release, the chaos rig for failure testing, and eventually the digital twin that live events calibrate. Since every source normalises to the same event language, the core genuinely cannot tell which one is feeding it — which is how you find out whether the abstraction holds before a city depends on it.

Non-overlapping windows are simply both granted. Where they overlap, arbitration runs in order: severity class, then commitment — an already-active corridor beats a new one — then the smaller ETA. The loser re-routes when an alternative costs little, and otherwise degrades to signal priority: an extended green rather than a full preemption. There is also a hard cap on simultaneous preemptions per zone, because enough corridors at once will gridlock the network they are trying to cross.

A deliberate boundary in the detection pipeline. Vision may auto-confirm traffic incidents — stopped vehicles, debris, wrong-way movement, queue spillback. Any detection involving a person routes to an operator and cannot dispatch anything on its own. That costs response time on that class of event, and it was accepted knowingly.
