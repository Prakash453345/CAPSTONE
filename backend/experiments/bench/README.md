# bench

The evaluation harness, build guide §8: scenario runner, metrics collector
(person-delay, person-throughput, max wait, stops, interlock violations, EV
travel time, cross-street delay penalty, recovery time), seeds, statistical
analysis (paired Wilcoxon, effect size), and plots.

Empty as of M0. Arrives in **M3** ("Baselines and KPI harness") — there is
nothing to benchmark before there's a controller and a baseline to compare it to.
